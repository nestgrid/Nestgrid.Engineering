# Template Maintenance

> Part of the **[Templates](README.md)**.

## Purpose

Template maintenance keeps reusable templates aligned with current standards and practices.

It ensures templates remain helpful as the methodology evolves.

## Guidance

Templates should be reviewed when documentation standards, decision formats, repository structure or engineering practices change.

Outdated templates spread outdated practice.

### Review Periodically

Templates should be reviewed at meaningful intervals or when standards change.

Review helps identify obsolete sections, unclear prompts and missing guidance.

### Update Before Propagation

When a standard changes, update the template first.

Future artefacts should inherit the improved structure.

### Preserve Compatibility

Template changes should consider existing documents.

Not every existing artefact must be rewritten immediately, but major inconsistencies should be addressed over time.

### Use Feedback

Contributor feedback should inform template improvements.

Templates should evolve based on real usage, not only theoretical structure.

### Keep Templates Discoverable

Templates should live in predictable locations and use clear naming.

If contributors cannot find templates, they will not use them.

## Key Takeaways

- Templates need maintenance.
- Standards changes should update templates first.
- Existing artefacts may need gradual alignment.
- Contributor feedback improves templates.
- Templates should be easy to find.
