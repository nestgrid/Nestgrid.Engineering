# Artefacts

The Lifecycle Mini Sample does not include a full set of workflow artefacts.

This directory is included to demonstrate the recommended product repository structure.

In a real product repository, this directory would contain lifecycle outputs such as:

- Product Briefs
- Architecture Packs
- Implementation Reports
- Test Strategies
- Security Assessments
- Deployment Guides
- Release Reports
