# Platform Artefacts

Platform artefacts capture operationalisation, deployment, publication or installation, configuration, observability, upgrades, rollback and operational readiness.

Typical artefacts:

- Deployment Guide
- Operational Readiness Review

Platform realises an operational strategy defined upstream. The concrete package depends on the product type: a library may need publication and consumer guidance, while an application may need installation, service registration and recovery procedures.
