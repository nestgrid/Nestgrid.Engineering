# Initiatives

This directory contains scoped lifecycle runs for significant engineering initiatives in the Lifecycle Mini Sample.

Each initiative may contain its own artefacts, decisions and reviews without mixing them into product-level records.

An initiative is a scoped execution of the same proportionate EOS lifecycle used for a product. It may begin at Opportunity Exploration, or start later when the opportunity and product context are already understood.

## Initiatives

- [2026-08 Multi-Currency](2026-08-multi-currency/README.md)

The sample uses an older date-month name for readability. New initiatives in a real repository should follow the ordered `<yyyy-mm-dd>-<sequence>-<initiative-name>` convention.
