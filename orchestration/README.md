# Orchestration

Orchestration defines how Roles and Profiles collaborate while performing the Engineering Operating System.

It coordinates participation without replacing the Engineering Handbook, lifecycle workflows, approval gates, artefacts or handovers.

## Models

- [Engineering Room](Engineering%20Room.md) - a persistent, multi-profile collaboration model for a product or initiative.

The isolated Role/Profile conversation remains a supported operating model. Use the model that best suits the work.
