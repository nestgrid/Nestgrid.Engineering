# Security

Security issues should be reported responsibly.

## Reporting a Vulnerability

Do not open a public issue for a security vulnerability.

Report security concerns through the repository owner's preferred private security channel. If no private channel is available, contact the maintainers privately before disclosing details publicly.

## What to Include

When reporting a vulnerability, include:

- A clear description of the issue.
- Steps to reproduce where safe and appropriate.
- The affected files, templates, samples or guidance.
- Any known impact.
- Suggested remediation if available.

## Scope

This repository primarily contains documentation, templates and samples.

Security concerns may include:

- Unsafe guidance.
- Exposed secrets in samples.
- Insecure sample configuration.
- Vulnerable sample dependencies.
- Documentation that encourages unsafe operational practice.

## Response

Maintainers should review security reports promptly, assess impact and coordinate remediation before public disclosure where appropriate.
