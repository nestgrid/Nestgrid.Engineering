# Contributing

Thank you for contributing to Nestgrid.Engineering.

This repository defines the engineering methodology, standards and practices used across the Nestgrid ecosystem. Contributions should preserve clarity, consistency and long-term maintainability.

## Contribution Principles

- Follow the structure and tone already established in the handbook.
- Prefer clear, concise guidance over long-form essays.
- Keep content product-neutral unless the document is explicitly a sample.
- Link related documents where it improves discoverability.
- Update templates before propagating a new documentation pattern.
- Record significant decisions when they affect methodology, structure or standards.

## Documentation Changes

Documentation should follow the relevant book or chapter template.

Each chapter should normally include:

- Purpose
- Guidance
- Key Takeaways
- Related Reading
- Navigation

When adding or renaming files, update all affected links.

## Pull Requests

Pull requests should be focused and reviewable.

Before opening a pull request:

- Check that Markdown links resolve.
- Confirm the change follows the established writing style.
- Keep unrelated changes out of the pull request.
- Explain why the change is needed.

## Review Expectations

Reviews should focus on correctness, clarity, consistency and maintainability.

Feedback should be specific, respectful and actionable.
