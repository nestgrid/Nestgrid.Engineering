# Documentation

This directory contains durable records for the Nestgrid Engineering Operating System.

The canonical Engineering Handbook is composed of the books in `/books`.

## Contents

`decisions/`

Decision records for significant choices made while evolving the operating system.

`initiatives/`

Scoped lifecycle runs used to improve the operating system.
