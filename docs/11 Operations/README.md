# Operations

The Operations stage defines how software is monitored, supported, maintained and improved after deployment.

Operational responsibility begins before production and continues for the lifetime of the system.

Good operations make systems understandable in production, reduce time to recover and turn real-world feedback into improvement.

## Purpose

To establish practices for running, supporting and maintaining production software responsibly.

## Objectives

Upon completing this book, engineers should be able to:

- Define operational ownership and support expectations.
- Use observability to understand production behaviour.
- Monitor health and respond to incidents.
- Maintain reliability and performance over time.
- Feed operational learning back into engineering.
