# Testing

The Testing stage defines how software is validated for correctness, reliability and maintainability.

Testing provides confidence that the solution behaves as intended and continues to do so as it changes.

Tests should protect important behaviour, not merely increase coverage numbers.

## Purpose

To establish a testing approach that validates meaningful behaviour, supports safe change and provides confidence throughout the lifecycle.

## Objectives

Upon completing this book, engineers should be able to:

- Define an appropriate testing strategy.
- Choose suitable test types for different risks.
- Test domain rules and important behaviours.
- Use automation to support fast feedback.
- Use coverage to find untested code.
- Use mutation testing to find ineffective tests.
- Maintain tests as part of the system.
