# New Product Discovery Bootstrap

This initiative captures handbook refinements discovered while bootstrapping Nestgrid.Diagnostics Discovery.

## Context

Nestgrid.Diagnostics required a new product repository to be started without existing product documentation.

The Engineering Handbook already contained the necessary guidance, but the initial Discovery bootstrap path required several pages to be read together.

## Scope

This initiative updates the Engineering Handbook to make new product Discovery bootstrap guidance explicit.

## Changes

- Added a New Product Discovery Bootstrap page to the Engineering Artefacts book.
- Clarified the minimum initial files for a new product repository.
- Clarified how product-discovered handbook feedback should be captured and promoted.
- Expanded database naming guidance to be provider-aware while preserving PostgreSQL `snake_case` as the standard convention.

## Decisions

No decision record was required for this initiative.

The changes refine existing workflow and handbook guidance based on product feedback.
