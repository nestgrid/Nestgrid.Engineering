# Role-Based Methodology

This initiative captures the refinement that makes the Engineering Operating System methodology role-based rather than agent-based.

## Context

The initial workflow catalogue used named agents directly in workflows and review artefact guidance.

That made the operating system easy to understand during early development, but it risked coupling the methodology to specific agent profiles.

## Objective

Update the live handbook, templates and workflows so they use role names. Keep named agents in the `agents/` catalogue as role-profile implementations.

## Scope

- Use role names in workflow participants and approval gates.
- Add Project Sponsor as the formal approval role.
- Use Independent Reviewer as the formal review role.
- Rename the Sentinel Review artefact template to Independent Review.
- Preserve historical records where agent names describe past work.
- Record the role-based methodology decision.
