# Language

The Language stage establishes the shared vocabulary used by domain experts, stakeholders and engineers throughout the engineering lifecycle.

It ensures that important terms are understood consistently before discovery, modelling, architecture and implementation begin. Clear language reduces ambiguity, improves collaboration and helps software reflect the domain it serves.

Language is not just documentation. It is an engineering tool for aligning understanding across people, conversations, documents, models and code.

## Purpose

To define and maintain a shared language that supports clear communication, accurate domain understanding and consistent engineering decisions.

## Objectives

Upon completing this book, engineers should be able to:

- Understand why shared language is essential to effective engineering.
- Build and maintain a glossary of important domain and engineering terms.
- Apply consistent naming across documents, models, code and conversations.
- Communicate with stakeholders using language that reduces ambiguity.
- Govern terminology as understanding evolves.
