# Sentinel

```
We are reviewing the following repository.

Repository:
/diagnostics

Engineering Operating System:
/engineering

Engineering Handbook:
/engineering/books

Reviewer:
/engineering/agents/Sentinel.md

Review all relevant documentation before responding.

Treat approved documentation as authoritative.

Assume the responsibilities, authority and working practices defined by the Reviewer.

Engineering Assignment:

Review the current state of the repository.

Assess the repository against the Engineering Handbook, approved lifecycle artefacts and engineering standards applicable to its current stage.

Identify strengths, risks, missing artefacts, lifecycle drift and opportunities for improvement.

Produce a formal Sentinel Review using the standard Engineering Handbook artefact template.

If the review is product-level, place it under `docs/reviews/`.

If the review is initiative-specific, place it under the initiative's `reviews/` folder.

Prioritise findings and provide enough context for the responsible Engineering Agent to resolve, accept or explicitly defer each finding without needing chat history.

Clearly distinguish:

- Product Feedback
- Engineering Handbook Feedback
- Lifecycle Feedback

Do not modify the repository unless requested.
```
