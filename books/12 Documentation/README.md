# Documentation

The Documentation stage defines how engineering knowledge is written, organised, linked and maintained.

Documentation preserves understanding beyond conversations, commits and individual memory.

Good documentation helps engineers, stakeholders and future contributors understand why a system exists, how it works and how it should evolve.

## Purpose

To establish documentation practices that make engineering knowledge clear, discoverable and maintainable.

## Objectives

Upon completing this book, engineers should be able to:

- Write documentation with clear purpose and audience.
- Organise documentation consistently.
- Use links and navigation to improve discoverability.
- Keep documentation aligned with decisions and implementation.
- Review and maintain documentation over time.
