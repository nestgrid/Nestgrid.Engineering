# Template Usage

> Part of the **[Templates](README.md)**.

## Purpose

Template usage defines how templates should be applied in real engineering work.

It helps teams gain consistency without creating unnecessary process.

## Guidance

Templates should be used when they improve quality, speed or discoverability.

They should be treated as trusted starting points that may still require thoughtful adaptation.

### Start from the Template

Where a standard template exists, new artefacts should usually begin from it.

This keeps structure and navigation consistent.

### Replace Placeholder Text

Placeholder content should be removed or replaced.

Completed artefacts should read as finished documents, not filled-in forms.

### Adapt Carefully

Templates may be adapted when the context requires it.

Adaptation should preserve the intent of the standard unless there is a clear reason to differ.

### Link to Related Artefacts

Template-based documents should include useful links to related documents, decisions or lifecycle stages.

Links make artefacts easier to navigate and maintain.

### Review Template Fit

If contributors repeatedly work around a template, the template may need improvement.

Usage feedback should influence maintenance.

## Key Takeaways

- Standard templates should be used where they exist.
- Placeholder text should not remain in completed artefacts.
- Adaptation should preserve template intent.
- Links improve discoverability.
- Repeated friction may indicate the template needs revision.
