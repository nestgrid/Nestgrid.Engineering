# Templates

The Templates stage defines how reusable documentation, decision and project templates should be created and maintained.

Templates help teams start from a consistent standard without rewriting common structure each time.

Templates should accelerate quality. They should guide thinking without replacing judgement.

## Purpose

To establish guidance for creating, using and maintaining reusable templates across the engineering lifecycle.

## Objectives

Upon completing this book, engineers should be able to:

- Understand when templates are useful.
- Create templates that guide rather than constrain.
- Keep templates aligned with the methodology.
- Use templates consistently across repositories.
- Maintain templates as standards evolve.
